# Security policy

Please do not report security vulnerabilities in public issues.

Report them privately through GitHub's **Report a vulnerability** button on the repository's Security tab. We aim to acknowledge reports within 3 business days.

Bypasses of a detector (a prompt that should be blocked but is not) are welcome as normal issues once the project is public, because they improve the benchmark dataset. Use a private report if a bypass affects a released version in a way that exposes user data.
